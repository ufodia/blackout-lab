# Changelog

Entries describe source versions. They do not imply a hosted service, package or binary publication.

## 0.1.0

Initial local experiment application:

- Fresh Chromium navigation with origin discovery and selected external-origin blocking.
- Protected first-party origin and disabled test-context service workers.
- Real baseline/blackout PNG captures and request-outcome evidence.
- Local HTML and JSON reports with sanitized request URL data.
- Loopback application server and browser-request protections.
- Built-in local demo, source/browser checks and English documentation.

Experiments cover a single initial-load observation. They do not exercise authenticated or multi-step workflows or establish a resilience certification.
